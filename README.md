# BiliOne

一个面向平板设备的非官方、非商业第三方视频客户端。

BiliOne 希望提供更适合大屏使用的观看体验，让浏览内容、观看视频、查看评论和管理个人内容变得简单、舒适。项目与哔哩哔哩无隶属、授权或赞助关系。

## 当前状态

当前版本为 `0.2.0` 测试版，功能仍在完善中，欢迎在真实设备上体验和反馈。

- 适配重点：8 英寸及以上平板；
- 当前性能实测基线：麒麟 980 及以上芯片；
- 包名：`io.github.shuyunr.bilione`；
- 应用名：`BiliOne`。

## 主要内容

- 推荐浏览、搜索和个人空间；
- 视频播放、清晰度、倍速、弹幕和评论；
- 横屏大屏、分屏和自由窗口使用体验；
- 播放记录、收藏、互动和基础账号功能。

## 使用边界

BiliOne 是独立的第三方项目，不保证所有设备、内容类型和账号功能都能正常使用。上游接口、网络环境或平台规则变化可能影响体验。

项目不提供视频下载，也不绕过会员、地区限制、DRM 或其他访问控制。使用过程中请遵守适用法律和相关平台规则。
