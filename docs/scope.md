# Third-party tablet client scope

本文件是产品范围的唯一入口，不记录具体页面实现细节、逐帧动画参数或历史变更。项目已从简单网页 Demo 演进为面向 11 英寸以上大屏平板的第三方客户端原型，14 英寸左右超大屏体验更好；动画连贯和流畅性能是核心目标。当前性能测试基线为骁龙 855 及以上，天玑、麒麟及其他处理器尚未系统性验证。

## 当前包含

- “关闭彩色卡片”开关默认开启；开启时所有视频卡片、评论卡片和头像取色卡片均回退为统一主题表面，关闭此开关后恢复封面/头像双色取色渐变。播放器画面外的封面渐变背景不受此开关影响。

- Android 6.0+（minSdk 23）、Kotlin、Compose Material 3、单 Activity。
- 通过 Bilibili Web API 展示个性化推荐、关注动态、搜索、番剧/影视、个人空间、收藏、历史、关注、消息、评论和弹幕。首页动态位于推荐与热门之间，左侧按服务端游标分页显示全部或有更新的关注 UP 主，右侧以适当左右留白复用个人主页的双列瀑布流、卡片详情展开、评论与形变动画，并提供不新开页面的“仅视频”筛选；单 UP 筛选使用动态首页 `feed/all + host_mid` 请求，切换 UP 后信息流回到顶部，点击后隐藏更新圆点并由后续 `portal` 响应确认云端已读。已读 UP 在当前动态页会话内保留原位置，切出动态标签并再次进入后才应用服务端的新顺序或移除结果。页面前台每 5 秒轮询首屏动态和 UP 列表，视频播放、共享封面以及动态详情覆盖层存在期间只缓存结果，返回动画完成后才提交到界面且不重播已有卡片入场动画。详情打开期间只锁定首页二级 Pager 的左右滑动，顶部胶囊仍可点按切页；子视频存在时系统返回优先交给当前视频页。视频动态继续使用应用内紧凑视频卡和独立动态来源锚点，封面、共享飞行层和窗口播放器统一使用 20 dp 圆角，保证多层视频入栈及返回时落回实际点击卡片。
- Media3 ExoPlayer 将 API 返回的 fMP4 片段包装为本地 DASH MPD，支持清晰度偏好、同一 TrackSelector 内的画质切换、0.5X～2.0X 倍速切换、256 MiB LRU 缓存和解码器能力缓存；默认优先 API 的首个备用 CDN，短时重复缓冲触发线路切换后持久记录成功 CDN 主机，并在后续视频中继续优先。设置中的“超高 / 极高”偏好会校验当前大会员状态。普通视频与番剧详情统一复用进程内唯一的详情 ExoPlayer，并由 MediaSessionService 发布系统媒体控件；普通详情的唯一 PlayerView/SurfaceView 固定挂载在 VideoScreen 的播放器层，窗口态与伪全屏只改变该真实容器的布局边界；番剧首页预览使用独立、页面私有的中等清晰度 TextureView/ExoPlayer；HDR/杜比视界额外自动渐进锁定最高窗口亮度并压暗播放器外背景。
- “我的”页在点赞消息与设置之间提供应用私有、不可导出的“缓存视频”：普通视频可按分 P、番剧影视可按剧集多选并统一选择清晰度，可选保存弹幕和字幕；选择列表按最早分 P/剧集到最新排列并默认选中首个尚未缓存的项目，已有任务或缓存不可重复选择。任务支持 500 ms 进度刷新、暂停、继续、仅 Wi-Fi、空间统计、单项和分组批量删除。该缓存使用独立的无容量淘汰持久缓存，不进入 256 MiB 播放 LRU；页面按合集/BV/季度显示首页同款合集卡，展开项以当前分 P/剧集标题为主标题，合集只在右侧内容区形变展开，播放后返回实际分 P/剧集封面。检测到可写可移除 SD 卡时可迁移完整缓存并校验后切换，SD 卡缺失时不显示该选项，已选 SD 卡拔出后保留卡片并标记不可用。缓存播放始终优先使用本地媒体；有网络时照常加载视频资料、评论、推荐、番剧季度和剧集等在线数据，断网时回退已保存数据且隐藏发送弹幕入口。会员媒体与账号及已确认授权绑定，会员确认失效后删除媒体和附属数据但保留虚化卡片；缓存不提供文件导出、分享，也不绕过付费、地区、DRM 或当前播放接口的授权结果。
- 持久化设置包含：跟随系统/浅色/深色三态主题、青色/Bili 粉/蓝色/紫色/绿色主题色、首页推荐 3–6 列、首页与播放页独立背景图及透明度、播放页设备状态信息显隐、减少动态效果、可关闭的实时毛玻璃、默认关闭的“限制加载速度”、Wi-Fi 与移动网络独立画质、自动连播及 3–10 秒倒计时、离开应用时暂停（默认开启，关闭后可后台听视频）、独立的双指捏合全屏与双指双击快进/快退等播放器手势、评论显示，以及弹幕默认开关/密度/区域/透明度/字号/速度与智能屏蔽。自定义背景仅绘制在页面最底层，默认透明度 60%，不进入共享元素图层，但与原主题背景共用页面淡入淡出进度；播放页背景从窗口态播放器边界挖空，不能遮挡真实视频表面。“限制加载速度”打开后在快速滚动时分批加载封面、头像和取色渐变，以减少掉帧但允许内容稍晚出现。确认无 SIM 的设备不显示移动网络画质，未知检测结果仍保留；网络画质按活动网络是否为蜂窝网络选择。播放器内仍可临时调整倍速与发送弹幕颜色。存储页可统计并清理可重新生成的播放、图片和 DASH 清单缓存；关于卡片静态展示开发者头像和 B 站用户名且不可跳转；缓存清理与恢复默认设置均不退出登录。
- 应用启动时输入方式为未选择；首次真实触屏按下锁定本次启动为触屏模式，首次真实外接 DPAD/GAMEPAD/JOYSTICK 按键或越过死区的方向轴输入锁定为控制器模式。设备连接、断开、系统虚拟 DPAD 与摇杆中心漂移都不切换模式；锁定后另一类输入不参与页面交互。控制器模式下首次触屏会被整笔拦截并提示“当前处于控制器模式”，用户可继续使用控制器，或选择重启软件并以一次性触屏模式重新创建页面。方向键、确认、返回、菜单与媒体键覆盖根导航、信息流、搜索、点播、直播、音乐、个人空间、专栏及主要弹窗；“我的”页不显示“我的消息”“回复或@我的”和“点赞消息”。首页第二级包含左上账号头像、搜索入口、频道 Bar，以及推荐页四个小功能按钮；头像和搜索仅在实际取得焦点时高亮。搜索第一次确认进入不弹输入法的独立导航态，可向下选择历史/热搜；再次确认输入框才进入编辑，IME 确认进入既有结果页；退出导航态或结果页后恢复第二级搜索焦点。推荐和直播使用“底部胶囊 -> 第二级 -> 第三级信息流”；动态第三级仅为左侧 UP 主菜单，确认当前 UP 后进入包含“动态 / 仅视频”和信息流的第四级，且只能用确认进入、BACK 返回；热门以分类控制栏为第三级、信息流为第四级。只有第一级的控制器确认可以切换大页面，任何信息流级别的左右导航都不能切换大页面或推荐、动态、热门、直播频道。控制器进入二级及更深层后底部根胶囊自动隐藏。动态“动态 / 仅视频”和热门分类栏贴着首页顶栏，推荐首行、动态/热门信息流及直播 Hero 顶部卡片须位于固定区域下方的完整安全视口。所有控制器焦点使用当前主题色高亮边框，文本输入保持“先聚焦入口、确认后编辑”的两阶段语义。点播页的控制器交互由设置项“在控制器模式中启用触屏播放页”控制，默认关闭，为专门的控制器模式播放器预留；开启后视频页启用控制器三态：页面导航 → 播放器直控 → 控件选择，播放器直控态确认进入全屏并复用单播放器浮动边界，左右按 5 秒 seek，下或确认进入控件选择，控件含播放/暂停、进度、画质、倍速、弹幕、选集（分 P/合集/剧集）与退出；播放结束层提供重新播放、下一集和相关推荐。视频页继续复用触屏页的评论区、楼中楼、推荐轨和头部内容；控制器正在导航时隐藏评论输入坞。BACK 按楼中楼或二级菜单 → 控件选择 → 全屏 → 内嵌播放器直控 → 页面导航逐层退出，退出视频页后恢复来源焦点与滚动位置。该设置关闭时视频页保持纯触屏行为，控制器只负责打开视频页，不提供播放页按键交互。
- “我的”控制器导航使用“底部根胶囊 → 左侧栏目 → 右侧内容”三级结构：确认当前“我的”根胶囊进入左栏，右键从栏目进入内容，BACK 按内容、栏目、根胶囊逐层返回，进入栏目后根胶囊隐藏。“我的关注”的搜索框只参与普通焦点导航，确认后才进入编辑并弹出输入法，返回退出编辑并收起输入法；“历史记录”隐藏右下角的搜索与回到顶部按钮。从首页打开搜索建议或进入搜索结果后，初始焦点必须位于搜索页面内部。个人主页资料信息胶囊向下连接当前栏目的首个内容控件，投稿、动态、合集和系列、追番追剧均可进入内容区，首行向上返回资料胶囊。
- 大会员且流中存在对应音轨时，播放器提供互斥的 Dolby / HiRes 开关；高级音质可按 Dolby 或 HiRes 优先级自动选择。设备不声明杜比视界/全景声能力时提供实验性解锁项，并明确提示不能保证播放成功。
- 二维码登录和本地 Cookie 持久化。
- 设置的“存储与关于”提供可选的移动端扫码授权与本地 Token 持久化，用于读取个人空间接口公开的 IP 属地；授权不替换现有网页登录，退出账号时一并清除。个人主页不提供授权按钮，已授权且字段存在时将 IP 属地内联显示在认证说明之后，无认证时直接占用该资料行。
- Web API 触发 `-352` 风控时弹出可交互验证码，通过后写入临时风控凭据并重试失败的关注横幅请求。
- 应用内全局沉浸式系统栏（边缘滑动临时唤出）、全屏播放器、返回优先级、手势控制和横竖屏/窗口恢复。
- Feed、搜索、账号页和个人空间分页、刷新及陈旧请求防护。
- 热门页包含网页版的综合热门、每周必看、入站必刷、排行榜和全站音乐榜分类；排行榜支持分区切换，周榜/音乐榜完整加载已返回期数并支持横向选择，综合热门支持续页。期数/分区横向滚动与首页二级分页手势隔离；热门信息流与推荐共用 Fast Path，用户打开“限制加载速度”后快速滑动才暂停新封面、取色和渐变，续页与预取仍避开高速滚动；热门卡的 UP 主名称不进入个人空间。
- 首页直播子页与“推荐 / 热门”并列，进入后再加载网页端前五条推荐直播、我的关注和直播房间列表；顶部使用严格 16:9 的左侧 TextureView 预览与右侧五张推荐卡，右侧卡内封面也按 16:9 显示，中部使用可横滑的小号关注卡，底部保持三列分页直播卡。右侧卡可直接打开对应房间，但选中、自动预览和共享动画均由左播放器统一承接；进入前按首页顶栏下方的安全视口检查左播放器，若受遮挡则先平滑滚回 Hero 顶端并等待边界稳定，此后才允许淡出标题、淡入静态封面、停止预览和执行共享动画，返回完成后标题淡入。Hero、关注和信息流使用包含板块及分区的独立来源锚点，同一房间重复出现时仍返回实际点击的板块。推荐流标题旁提供“所有分区”入口，进入带顶部一级菜单和子分区网格的索引页；支持下拉刷新和共享封面进入独立直播播放页。我的关注先读取网页首页聚合接口的 `room_list[].module_info.id == 13` 模块及在线总数，再在总数超过首页 6 张卡片时分页补齐完整关注直播；合并时保留首页顺序并用完整记录补齐稳定房间封面，仍缺图时按房间号读取房间信息。关注卡、进入共享动画和返回共享动画统一使用当前关键帧，缺失时共同回退房间封面；卡片持续上报实际封面边界，并在共享动画期间隐藏自身封面以避免重影。底部列表继续使用已验证的兼容房间列表接口，避免新版分区 WBI 列表的 `-352` 触发全局验证码。预览流只在直播子页可见时准备，首帧前保留房间封面，且只能在实际首帧到达后淡出遮罩；离开后暂停，不做后台预加载，播放地址失效时自动换备用流、刷新播放地址并低频重试。独立直播播放页在防休眠设置开启且页面可见时保持屏幕常亮。所有来源的直播卡返回统一为“暂停直播 → 来源封面隐藏 → 播放器封面静止且页面约 200 ms 淡出 → 封面飞回”；共享封面落地后先与来源卡封面重叠两个提交帧再移除，普通卡和直播预览均不得出现单帧空窗。
- 历史记录支持“全部 / 仅视频 / 仅直播 / 仅专栏”筛选和 cursor 续页；直播和 PGC 作品同时合并本地即时观看记录。番剧索引进入的作品立即保存本地分集身份与进度，并使用同一身份上报云端 PGC 心跳；服务端记录到达后按季去重合并。
- 搜索页开放独立专栏、番剧和影视分类；搜索结果网格的 3–6 列列数跟随首页设置并应用于全部分类；专栏支持综合、最新发布、最多点击、最多喜欢和最多评论排序，番剧/影视复用个人空间追番追剧海报卡片，并进入与视频页、专栏页平级的番剧/影视播放页。
- 专栏卡片固定保留 16:9 视觉位：有封面时显示封面，无封面时按文章稳定 ID 生成主题色视觉底图；两种状态均以该视觉位执行可中断反向的共享边界转场。
- 原生专栏页支持 Opus 重定向后的结构化正文、B 站表情、视频链接卡、半视口高度图片裁剪与完整图片预览，并在正文后接续复用现有卡片和输入坞的类型 `12` 评论信息流。视频与专栏评论统一解析 `up_action`，在回复数后显示 UP 主点赞、回复或两者组合状态；评论长图在卡内维持缩略图请求，打开时用 WebView 分块渲染移除 B 站尺寸派生后缀的完整原图，保存时直接写入原图响应字节，避免单个超高 Bitmap 的解码与纹理上限。

- 单 Canvas 弹幕使用时间窗口二分检索；视频和番剧按 6 分钟分段请求并只常驻当前段及前后各一段，seek 先取当前段、再补相邻段，旧请求按 generation 丢弃。普通视频使用有上限且普通追加不失效的文字位图缓存，单帧位图创建有界，HDR/杜比视界直接绘制文字。直播消息通过有界队列短周期合并；实际播放和首个视频帧同时就绪前不激活弹幕，首次激活不回放完整房间积压。视频/番剧设置只展示“屏蔽等级 1–5级”，内部在每个分段稳定排序后按每五条保留 5/4/3/2/1 条，不读取服务端权重，本地即时弹幕始终保留；直播不使用该设置。智能防挡可读取上游 `dm_mask`，后台把 webmask SVG 降采样成轮廓；SVG 填充路径固定代表允许显示弹幕的背景区域，人物遮挡区始终由视频区域与允许区域做差得到，不按轮廓面积切换方向。绘制时按播放器真实时间裁掉人物区域上的弹幕；时间轴中的偶发坏帧跳过，两个有效轮廓间不超过 80 ms 的空检测沿用上一轮廓，持续空白段正常解除。整份蒙版缺失或不可解析时回退普通弹幕。全屏交接前一帧同步停止弹幕。暂停时中心播放按钮独立于自动隐藏的进度条。全屏左右中线各有一个同步的开锁/闭锁按钮并与进度条共用显隐计时；锁定后单击只切换该控制层显隐，其余普通控制及播放器手势关闭，退出全屏自动解锁。双指接触独占播放器手势，只有实际外扩/捏合才切换全屏；亮度和音量指示器带淡入淡出。
- 根页面横向切换优先于后台工作：暂停首页续载、封面预取和“我的”页可恢复搜索/翻页，切换结束后再恢复必要加载。共享封面飞行拥有最高帧优先级，目标页重型组合和网络/媒体加载不得与飞行重叠。
- 评论作者首次进入个人空间时，先在最多 280 ms 的准备窗口内预组合空间骨架、稳定目标边界并预解码共享头像，然后再播放轻量转场。
- 首页开屏提供有硬超时的本地组件预热遮罩，不等待网络，并可预创建空闲播放器引擎；设置可持久化选择自定义启动遮罩图，自定义图裁剪覆盖全屏，未设置或图片不可读时只在屏幕中间显示当前内置图标。启动遮罩始终位于页面、播放器控制层和弹幕之上；遮罩显示期间须同步抑制独立弹幕 Surface，避免长时间后台后恢复时弹幕穿透遮罩。普通详情页不使用根层播放器宿主或透明合成孔。全屏必须保留 VideoScreen 内黑色背景 80、真实播放器 90、控制层 100 的同父级顺序，不能借由页面挖透明洞或整页淡出来透出低层 Surface。伪全屏无描边，Android 12 以下落位为直角，画面外区域使用封面双色渐变，并允许通过持久化设置调节该渐变亮度至纯黑而不改变视频画面。信息流使用可集中回退的 Fast Path；图片与调色削减由“限制加载速度”控制，预取、阴影和逐项揭示仍可在滚动时降级。滚动状态由调色板协程观察，不作为所有可见卡片的组合参数，网格不切换整屏 GPU 层。首页视频卡不绘制外边描边，静止与移动全程保留同一圆角。运动中的视频/头像点击会先快速制动并以最新坐标开始共享转场；视频共享动画结束前暂停首页后台预取，不激活媒体或页面数据。卡片自动滚入完整视口后保存安全视口锚点，退出播放页时保留该位置，不恢复点击前的旧区域；视频页返回淡出只作用于 Compose 页面内容，使视频卡、操作卡描边与内容同步消失，不能把 SurfaceView 纳入离屏半透明层。
