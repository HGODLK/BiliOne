# BiliOne 项目范围

## 它能做什么

BiliOne 是一个面向平板大屏的哔哩哔哩第三方客户端，覆盖：

- **浏览**：推荐、动态、热门、直播、番剧/影视六类索引
- **观看**：视频播放、弹幕（智能防挡）、评论、分 P/合集、进度记忆、字幕
- **搜索**：综合 / 视频 / 番剧 / 影视 / 直播 / 专栏 / 用户 七类
- **内容**：番剧、影视、直播、音乐、专栏
- **个人内容**：收藏、历史、稍后再看、关注、私信、消息、点赞消息
- **离线缓存**：在应用内缓存允许离线观看的视频，账号与授权绑定

## 适配与性能

- 面向 11 英寸以上横屏平板，14 英寸左右体验更佳；小尺寸平板可运行，布局降级
- 支持分屏、自由窗口与系统强制方向，页面按实际窗口尺寸自适应
- 最低支持 Android 7.0（API 24）
- 动画与播放流畅度在骁龙 855 及以上芯片的平板上经过实测（该档位今天属中低端）；天玑、麒麟及其他处理器尚未系统性验证

## 需要登录的功能

- 无需登录即可：浏览推荐/热门/动态、搜索、播放视频（清晰度受限）、看弹幕和评论、查看公开个人资料
- 需要登录：发弹幕、点赞、投币、收藏、关注、发评论、私信与消息、稍后再看、收藏管理、观看进度云端同步等

## 登录方式

- 仅支持用哔哩哔哩手机 App 扫码登录（二维码），无需输入账号密码
- 个人主页的 IP 属地为可选的附加授权：在“设置 → 存储与关于”中扫码授权后显示，与登录相互独立

## 离线缓存说明

- 缓存仅在当前播放接口明确允许当前账号播放的范围内进行
- 缓存为应用私有、不可导出、不可分享，不提供媒体文件或播放地址导出
- 会员内容与发起缓存的账号及授权绑定（带授权租期）；会员状态确认失效后，缓存内容不可用
- 不绕过会员、付费、地区、DRM 或当前播放接口的授权结果
- 字幕仅从哔哩哔哩官方字幕服务获取并绑定校验

## 不保证事项

- 直播、番剧、影视的完整上游内容覆盖、付费内容、地区限制内容、全部账号流程兼容
- 所有视频编码、音视频流组合和厂商设备的兼容
- 评论图片上传、带图笔记发布等未提供的管理能力
- 番剧/影视播放页和付费合集的完整选集语义
- 上游非稳定 Web API 永久可用；上游接口或平台规则变化可能让部分功能暂时失效
