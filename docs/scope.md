# BiliOne 项目范围

## 项目定位

BiliOne 是面向平板设备的独立第三方视频客户端，重点关注横屏大屏浏览、视频观看和日常互动体验。

当前版本 `0.2.0` 为测试版，功能尚未完善。项目以 8 英寸及以上屏幕为主要适配范围，当前性能实测基线为麒麟 980 及以上芯片。

## 主要方向

- 更适合平板的内容浏览和视频观看；
- 清晰、连续的评论与弹幕互动；
- 横屏、分屏和自由窗口下的舒适使用；
- 在公开、透明的前提下持续改进体验。
